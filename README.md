# Java-Competition-Game

🏎️ Java-Competition-Game: Neon Highway

In this project, I am building a 2D Top-Down Infinite Racer for a programming competition at my college (FSHN).

Ndërtuar me Java Swing si nje projekt shkollor brenda 10 ditesh.

## Si mund ta luani lojen?
**Nuk ke Java** → shkarko [NeonHighwayV2.2_exe.zip](https://github.com/Orest-Z/Java-Competition-Game/releases/tag/V2.2.1)
Beji unzip folderit dhe hap Neon Highway.exe


**Ke Java 17** → shkarko [NeonHighwayV2.2_jar.zip](https://github.com/Orest-Z/Java-Competition-Game/releases/tag/V2.2.0)
Beji unzip folderit dhe thjesht hapni filen NeonHighway.jar


Kontrollet e lojes:
← → lëviz  |  ESC pause

## Features kryesore te lojes
**1.Shop** -> Nje dyqan ku ju mund te blini skine te ndryshme te maps si dhe te makines se juaj me ane to coinsave qe beni collect ne autostrade
**2.Leaderboard** -> Nje panel ku shfaq 10 lojtaret me score-in me te larte 
**3.Settings** -> Ketu keni mundesine qe te ndryshoni vetem 3 opsione te ndryshme per momentin sic jane (Enter full screen, Enable/Disable Background Music, Enable/Disable SFX )
